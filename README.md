# DevBoard

DevBoard is a full-stack project management application.

The backend is built with ASP.NET Core Web API and the frontend with Angular.

## Stack

### Backend
- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL

### Frontend
- Angular
- TypeScript

## Features

- projects
- tasks
- project members
- comments
- tags
- authentication
- authorization
